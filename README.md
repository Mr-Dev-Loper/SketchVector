# SketchVector - Whiteboard Web App

A feature-rich whiteboard application built with vanilla JavaScript.

## Features
- Drawing tools: Pen, Highlighter, Shapes, Text
- Selection and manipulation
- Undo/Redo
- Local storage persistence
- Export to PNG/SVG/JSON
- Dark/Light themes
- Keyboard shortcuts
- Grid with snap

## Keyboard Shortcuts
| Key | Action |
|-----|--------|
| V | Select tool |
| P | Pen tool |
| H | Highlighter |
| E | Eraser |
| R | Rectangle |
| C | Circle |
| L | Line |
| A | Arrow |
| D | Diamond |
| T | Text |
| G | Toggle grid |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Delete | Delete selected |
| Space+drag | Pan canvas |
